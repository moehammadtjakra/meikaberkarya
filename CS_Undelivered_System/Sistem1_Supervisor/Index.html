Sesi Manual — memeriksa…

Tracking memakai endpoint platform VIP J&T, yang diautorisasi lewat authToken & device-no dari sesi login VIP Anda. Keduanya ditempel manual dari DevTools; sekali tempel dipakai untuk semua resi. Kalau tracking mulai gagal (unauthorized), sesinya kedaluwarsa — tempel ulang.

  1. Login di login-newvip.jet.co.id → buka Tracking → lacak 1 resi.
  2. Tekan F12 → tab Network → klik permintaan trace/list.
  3. Di Request Headers, salin nilai authToken dan device-no.

Ambil dari sesi VIP yang sedang aktif. Kalau Anda logout dari VIP, token bisa ikut mati. Foto bukti kurir hanya bisa diambil lewat jalur VIP ini — dan link fotonya berlaku ±24 jam, jadi jalankan tracking berkala agar link-nya tetap segar.

Log proses — langkah demi langkah, sama persis dengan yang tercatat di Apps Script → Executions

Solusi sementara — perlu Anda ketahui
Fitur ini memakai endpoint platform VIP J&T, bukan API resmi, dan strukturnya bisa berubah kapan saja tanpa pemberitahuan. Karena itu jeda antar-permintaan dibuat sopan, dan proses berhenti sendiri kalau 5 permintaan beruntun ditolak. Foto bukti kurir ikut terambil dari sini, tapi link-nya berlaku ±24 jam — jalankan tracking berkala agar tetap bisa dibuka.

Begitu API resmi J&T disetujui, hanya satu fungsi yang diganti; seluruh sheet, dashboard, dan tampilan ini tidak berubah.

Kalau bermasalah, jalankan cekSesi() lalu tesSatuResi() dari editor Apps Script — keduanya menjelaskan persis apa yang gagal.
